# Rick and Morty App

Prueba técnica frontend desarrollada con Next.js, TypeScript, TailwindCSS y Context API.

## Funcionalidades

- Listado de personajes desde la API de Rick and Morty
- Búsqueda de personajes por nombre
- Vista responsive de tarjetas
- Página de detalle de personaje
- Sistema de favoritos
- Persistencia de favoritos con localStorage
- Máximo de 5 favoritos
- Reordenamiento de favoritos
- Gráfica por especies
- Manejo de loading y errores
- Uso de React ICONS (requiere instalacion de dependencias)
- Uso de recharts para la parte grafica (requiere instalacion de dependencias)

## Integración de API

Este proyecto consume la API REST de Rick and Morty utilizando fetch y manejo asíncrono de datos.

Para esta prueba técnica se eligió REST como la solución más práctica y adecuada para los requerimientos del proyecto.

## Librerías utilizadas

- React Icons para iconografía de la interfaz
- Recharts para visualización de gráficas
